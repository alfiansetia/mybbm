4 / Arsitektur & AI — Feasibility 20% + Innovation 25%

1 codebase: Build · Secure · Scale

Build + Scale

React 19 + Vite + Tailwind PWA → Express server.ts → Cloud Run asia-southeast2 scale-to-zero. Firestore: user owner-scoped, stations public-read.

AI hemat (Innovation)

Gemini Flash server-side only. Downscale 1600px, strict-JSON, temp 0, null-bukan-tebakan. Clamp tangki. Gagal jujur 503/502/400 + manual.

Secure: default-deny rules, tulis wajib login, delete dilarang, cooldown server-enforced, PII minim, key runtime-only.
